# Data

## Processed numerical data

- `sci8_school_building_numerical_data.xlsx`: final selected variables and annual performance indicators.
- `static_variables_annual_performance.xlsx`: static building variables and annual simulation indicators.
- `annual_economic_carbon_indicators.xlsx`: annual energy, carbon and economic indicators.

## Geometry data

- `teaching_building_OBJ_summary_3356.zip`: summarized teaching-building OBJ models.

## Hourly data

The complete hourly dataset contains thousands of building-level Excel files and is too large for a normal GitHub repository. This repository includes representative samples and a complete manifest:

- sample files: `samples/time_series/*.xlsx`
- full manifest: `metadata/time_series_manifest.csv`

Each hourly file corresponds to one teaching building and can store 8760-hour energy, PV generation, carbon emission and derived indicators.
