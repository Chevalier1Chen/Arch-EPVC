Arch-EPVC School Building Dataset

Numerical building attributes, annual simulation indicators, OBJ geometry and hourly simulation data for school buildings in Shandong Province, China.

Download Data

  • Numerical data and annual indicators
  • OBJ geometry dataset
  • Complete hourly dataset: 3,356 workbooks, seven ZIP archives
  • Hourly workbook examples
  • Variable descriptions, file index and checksums

Each hourly archive is independently extractable. Extract all seven archives into the same directory to assemble the collection.

Data-only publication. Platform source, training code, model weights, research figures and presentation materials are excluded from the current version. GitHub repository
