- Hourly source: 3,356 XLSX workbooks, 3,296,345,351 bytes. Release archives preserve each workbook without editing its contents. Packaging is not a check of 8,760-hour completeness or numerical accuracy.
- Included research source and paired checkpoints were recovered from the original Documents research workspace. Model provenance is documented in `research/README.md`.
- GitHub Pages downloads are bundled under `docs/downloads/` so that they work with the Pages deployment root.
- The platform source includes real browser ONNX models, campus geometry and data. The existing-building hourly module also references `/vendor/onnx/`, `/models/second-route-hourly-lstm.onnx`, `/models/second-route-static.f32` and `/models/second-route-scalers.json`; these assets were absent from the source public directory. This source snapshot must not be described as fully verified or immediately deployable for every function.

- Repository created through the official GitHub CLI after account authorization. Publication does not imply a new experimental validation.
