# Simulation workflow

This folder stores Grasshopper definitions and helper scripts used to process OBJ geometry and simulation inputs.

- `grasshopper/`: Ladybug Tools / Honeybee / EnergyPlus workflow files.
- `scripts/`: Rhino and Grasshopper Python helper scripts for importing OBJ models, splitting roof and facade surfaces, mapping building identifiers and importing campus basemaps.

Before running batch simulation, update file paths inside Grasshopper components to match the local data folder.
