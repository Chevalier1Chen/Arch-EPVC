# Arch-EPVC 学校建筑能耗、光伏与碳排放研究

**[论文项目主页](https://chevalier1chen.github.io/Arch-EPVC/)** · **[打开 Arch-EPVC 在线平台](https://arch-epvc.vercel.app)** · **[数据集下载](https://github.com/Chevalier1Chen/Arch-EPVC/releases/tag/v0.1.0)**

本项目融合教学建筑三维形态、结构化属性及气象时序，研究年度与逐时双尺度性能评价，面向新建学校早期设计与既有教学建筑性能、光伏潜力评价。在线平台继续在独立站点运行，GitHub 项目页提供研究介绍、平台入口与数据下载。

本仓库只公开数据及必要说明：建筑数值属性、年度模拟指标、OBJ 几何数据和逐时模拟数据。

当前版本不包含平台源码、训练源码、模型权重、论文图件、展示表格、PPT 或建模结果包。数值数据工作簿和几何编号索引属于数据集本体，予以保留。

- [研究项目页与数据下载](https://chevalier1chen.github.io/Arch-EPVC/)
- [完整逐时数据下载](https://github.com/Chevalier1Chen/Arch-EPVC/releases/tag/v0.1.0)：3356 个工作簿，分为 7 个独立压缩包。
- `data/processed/`：建筑属性及年度模拟指标。
- `data/geometry/`：教学建筑 OBJ 数据包及编号索引。
- `data/samples/time_series/`：8 个逐时数据样例。
- `data/metadata/`：字段说明、文件对应关系及校验值。

七个逐时压缩包可分别解压；下载全部后解压到同一目录即可合并。本次仅调整公开内容，不修改数据数值，也不代表重新审核了模拟精度或逐时完整性。
